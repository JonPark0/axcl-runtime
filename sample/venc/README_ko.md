### 설명
이 모듈은 SDK 패키지의 일부로, 비디오 인코딩 유닛(H.264, H.265, JPEG, MJPEG)의 샘플 코드를 제공합니다. 고객이 비디오 인코딩 관련 인터페이스의 사용법을 빠르게 이해하고 익힐 수 있도록 돕는 것을 목적으로 합니다. 이 코드는 비디오 인코딩 모듈 초기화, 인코딩 Send 스레드를 통한 프레임 데이터 전송, 인코딩 Get 스레드를 통한 인코딩된 스트림 데이터 획득 및 저장, 비디오 인코딩 모듈 초기화 해제 과정을 보여 줍니다.

컴파일 후 실행 파일 `axcl_sample_venc`는 /opt/bin/axcl 디렉터리에 있으며, 비디오 인코딩 기능을 검증하는 데 사용할 수 있습니다.

- **-w**: 소스 데이터의 너비를 설정합니다.
- **-h**: 소스 데이터의 높이를 설정합니다.
- **-i**: 입력 소스 데이터의 경로입니다.
- **-l**: 입력 소스 데이터의 YUV 포맷입니다(1: I420; 3: NV12; 4: NV21; 13: YUYV422; 14: UYVY422). 기본값은 1입니다.
- **-N**: 인코딩 채널 수를 설정합니다. 기본적으로 H.264, H.265, MJPEG, JPEG을 인코딩하는 4개 채널을 활성화합니다.
- **-n**: 반복 인코딩을 활성화한 경우 인코딩할 프레임 수를 지정합니다.
- **-W**: 인코딩된 스트림을 파일에 쓸지 여부입니다(기본값은 1로, 파일에 씁니다. 0: 쓰지 않음).

> [!NOTE]
>
> - 예제 코드의 일부 파라미터는 최적값이 아닐 수 있으며 API 시연 목적으로만 사용됩니다. 실제 개발에서는 사용자가 구체적인 비즈니스 시나리오에 맞게 파라미터를 설정해야 합니다.
> - H.264/H.265는 최대 8192x8192 해상도를 지원합니다.
> - JPEG/MJPEG은 최대 16384x16384 해상도를 지원합니다.

### 예제
실행에 성공하면 Ctrl+C를 눌러 종료하세요. 현재 디렉터리에 .264, .265, .jpg, .mjpg 등의 확장자를 가진 스트림 파일이 생성되어야 합니다. 사용자는 이 파일을 열어 실제 결과를 확인할 수 있습니다.

1. 도움말 정보 보기
   ```bash
   axcl_sample_venc -H
   ```

2. 채널 2개를 활성화하여 1080p NV12 포맷 인코딩(채널 0: H.264, 채널 1: H.265)
   ```bash
   axcl_sample_venc -w 1920 -h 1080 -i 1080p_nv12.yuv -N 2 -l 3
   ```

3. 채널 2개를 활성화하여 3840x2160 NV21 포맷 반복 인코딩(채널 0: H.264, 채널 1: H.265), 프레임 10개 인코딩
   ```bash
   axcl_sample_venc -w 3840 -h 2160 -i 3840x2160_nv21.yuv -N 2 -l 4 -n 10
   ```

4. 해상도 1920x1080, YUV420P 포맷의 MJPEG 스트림 1개 인코딩, 프레임 5개 인코딩
   ```bash
   axcl_sample_venc -w 1920 -h 1080 -i 1920x1080_yuv420p.yuv -N 1 --bChnCustom 1 --codecType 2 -l 1 -n 5
   ```
