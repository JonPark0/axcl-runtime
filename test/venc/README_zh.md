1. 功能说明：

本模块是 SDK 包中提供的视频编码单元（H.264、H.265、JPEG、MJPEG）示例代码。
旨在帮助客户快速理解和掌握视频编码相关接口的用法。
代码演示了以下流程：视频编码模块初始化、通过编码 Send 线程发送帧数据、
通过编码 Get 线程获取并保存编码码流数据，以及视频编码模块去初始化。

编译完成后，可执行文件 sample_venc 位于 /opt/bin 目录下，可用于验证视频编码功能。
•-w：配置源数据宽度。
•-h：配置源数据高度。
•-i：输入源数据的路径。
•-l：输入源数据的 YUV 格式（1：I420；3：NV12；4：NV21；13：YUYV422；14：UYVY422）。默认为 1。
•-N：配置编码通道数。默认开启四个通道，分别编码 H.264、H.265、JPEG 和 MJPEG。
•-n：开启循环编码时，指定编码帧数。
•-W：是否将编码码流写入文件（默认为 1，表示写入文件；0：不写入）。

2. 使用示例：

示例 1：查看帮助信息
     sample_venc -H

示例 2：开启两个通道编码 1080p NV12 格式（通道 0：H.264，通道 1：H.265）
     sample_venc -w 1920 -h 1080 -i 1080p_nv12.yuv -N 2 -l 3

示例 3：开启两个通道循环编码 3840x2160 NV21 格式（通道 0：H.264，通道 1：H.265），共编码 10 帧
     sample_venc -w 3840 -h 2160 -i 3840x2160_nv21.yuv -N 2 -l 4 -n 10

3. 执行结果：

运行成功后，按 Ctrl+C 退出。当前目录下应生成扩展名为 .264、.265、.jpg 或 .mjpg 的码流文件。
用户可打开这些文件查看实际效果。

4. 注意事项：

•a) 示例代码中的部分参数可能并非最优，仅用于演示 API 用法。
    在实际开发中，用户需要根据具体业务场景配置参数。
•b) H.264/H.265 最大支持 8192x8192 分辨率。
•c) JPEG/MJPEG 最大支持 16384x16384 分辨率。
